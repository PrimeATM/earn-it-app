# Earn It • Multi-Kid Edition

A fun, colorful chore and allowance tracker for multiple kids with individual wheels, parent approvals, and reward banks.

## Features

✨ **Multi-Kid Setup** - Start with 2 kids (easily add more)
🎡 **Individual Wheels** - Each kid gets their own task wheel with personalized rewards
⏱️ **15-Minute Cooldown** - After spinning, kids wait 15 minutes before they can spin again
✅ **Parent Approval** - Parents review and approve completed tasks before points are added
🏦 **Reward Bank** - Points accumulate and kids can claim rewards they choose
🎨 **Age-Appropriate Tasks** - Suggested tasks adjust based on kid's age (6-18 years)
🌈 **Bright & Playful Design** - Beautiful, kid-friendly interface with vibrant colors

## Getting Started

1. **Open the app** - Download `index.html` and open in your browser
2. **Setup** - Enter each kid's name and age
3. **Start tracking** - Kids spin the wheel, complete tasks, parents approve, points go to reward bank
4. **Custom tasks & rewards** - Add your own tasks and rewards for each kid

## How It Works

### For Kids
1. Click **SPIN** to see what task they got
2. Complete the task in the real world
3. Come back when done and hit **Mark as Done**
4. Wait for parent approval
5. Once approved, points go into their reward bank
6. Use points to claim rewards from the reward bank

### For Parents
1. **Approve/Reject Tasks** - Review completed tasks in the "Parent Approvals Needed" section
2. **Manage Tasks & Rewards** - Customize age-appropriate tasks and rewards for each kid
3. **Monitor Progress** - See each kid's earning progress and reward spending

## Local Storage

All data is stored in your browser's local storage. No accounts needed, no cloud sync.

## Customization

- **Edit tasks** - Modify `AGE_TASKS` in the JavaScript to customize suggested tasks
- **Change rewards** - Update `DEFAULT_REWARDS` to set your family's reward options
- **Adjust cooldown** - Change the `15 * 60` (15 minutes) to any duration you want

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge) on desktop, tablet, and mobile.
